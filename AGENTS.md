# AGENTS.md

Guidance for AI agents working in this repository.

## What This Is

Terraform provider for Gravitee APIM (API Management). Most Go code is **generated by Speakeasy** from an OpenAPI spec — do not edit files marked with `// Code generated by Speakeasy`. Custom behavior lives in hand-maintained files and in marked regions inside generated code (e.g. `// BEGIN GRAVITEE CLOUD INIT` in `provider.go`).

## Build & Test Commands

```bash
# Build
go build

# Full code generation (requires speakeasy CLI + Docker for doc-gen)
make speakeasy

# Generate guide markdown only (graviteeio/doc-gen Docker image)
make doc-gen

# Lint (OAS + Terraform fmt + commitlint + cloud-init marker check)
make lint
make lint-fix          # fix Terraform formatting

# Sync OAS from upstream APIM
make sync-oas

# Unit tests (no APIM required)
make unit-tests

# Acceptance tests (requires running APIM)
make acceptance-tests

# Example tests (requires running APIM + local provider build)
make examples-tests

# Run a single acceptance test
APIM_USERNAME=admin APIM_PASSWORD=admin APIM_SERVER_URL=http://localhost:30083/automation \
  TF_ACC=1 go test -count=1 -v -run TestAccApiv4Resource ./tests/acceptance

# Run a single unit test
go test -count=1 -v -run TestSomething ./internal/...

# Local Kind cluster for APIM
make start-cluster                          # full mode
APIM_MINIMAL=true make start-cluster        # minimal (faster, management API only)
make stop-cluster
```

## Generated vs Hand-Written

### Generated — do not edit directly

| Output | Tool | Source |
|--------|------|--------|
| `internal/sdk/`, most of `internal/provider/`, `internal/planmodifiers/`, `internal/validators/`, `main.go` | Speakeasy | `automation-api-oas.yaml` + `.speakeasy/overlays/` |
| `docs/index.md`, `docs/resources/*.md` | tfplugindocs (`go generate` in `main.go`, run as part of `make speakeasy`) | Provider schema + `examples/` + `templates/` |
| `templates/guides/docgen_*.md` | doc-gen (`make doc-gen`) | `.docgen/config/default.yaml` + `.docgen/config/tmpl/*.md.tmpl` + `examples/use-cases/` chunks |

`make speakeasy` runs `make doc-gen` first, then `speakeasy run`, then deletes ephemeral outputs: `USAGE.md`, `examples/data-sources/`, `docs/data-sources/`, `examples/README.md`.

Files listed in `.genignore` are **not** overwritten by Speakeasy even though similar paths may be generated — notably all of `examples/resources/**` and `CONTRIBUTING.md`.

### Hand-written — safe to edit

| Path | Purpose |
|------|---------|
| `automation-api-oas.yaml` | Base OpenAPI spec (synced via `make sync-oas`) |
| `.speakeasy/overlays/**`, `.speakeasy/workflow.yaml`, `.speakeasy/speakeasy-modifications-overlay.yaml` | Schema and generation customizations |
| `.genignore` | Files Speakeasy must preserve |
| `.docgen/config/default.yaml`, `.docgen/config/tmpl/*.md.tmpl` | Guide prose and chunk wiring |
| `examples/use-cases/**`, `examples/tutorials/**` | Tutorial Terraform configs |
| `examples/resources/**` | Minimal per-resource examples for registry docs (curated, in `.genignore`) |
| `tests/**` | **Entirely hand-written** — acceptance tests, example tests, testdata, utilities; nothing here is generated |
| `internal/provider/gravitee_cloud.go` | Gravitee Cloud auth / server URL resolution |
| `internal/provider/customtypes/**` | `TrimmedString`, `RFC3339` custom Terraform types (referenced from overlays) |
| `internal/planmodifiers/stringplanmodifier/immutable.go`, `normalize_path.go` | Custom plan modifiers |
| `internal/planmodifiers/listplanmodifier/ignore_empty_list.go` | Custom plan modifier |
| `internal/sdk/internal/hooks/registration.go` | Generated once, then free to edit |
| `hack/`, `Makefile`, CI config | Project infrastructure |

Most files under `internal/planmodifiers/` and `internal/validators/` are Speakeasy-generated scaffolding; only the custom modifiers listed above are hand-maintained.

## Architecture

### Code generation flow

```
automation-api-oas.yaml + .speakeasy/overlays/
        │
        ├─► Speakeasy ──► internal/sdk/, internal/provider/, main.go
        │                      │
        │                      └─► tfplugindocs ──► docs/
        │
examples/use-cases/*.tf + .docgen/config/tmpl/*.md.tmpl
        │
        └─► doc-gen (make doc-gen) ──► templates/guides/docgen_*.md
                                              │
                                              └─► tfplugindocs ──► docs/guides/
```

Config: `.speakeasy/gen.yaml`, `.speakeasy/gen.lock`, `.speakeasy/workflow.yaml`.

### Provider structure (`internal/provider/`)

- **Resources** (10): `apim_apiv4`, `apim_application`, `apim_dictionary`, `apim_documentation_api`, `apim_documentation_portal`, `apim_group`, `apim_portal`, `apim_portal_listing`, `apim_shared_policy_group`, `apim_subscription`
- **Data sources** (10): mirror the resources above for read-only access
- Each resource has `*_resource.go` (CRUD) and `*_resource_sdk.go` (type mapping); data sources follow the same pattern
- `provider.go` — provider config, auth, schema (generated, with `// BEGIN GRAVITEE CLOUD INIT` hook)
- `reflect/` and `typeconvert/` — Terraform ↔ SDK type conversion (generated)
- `customtypes/` — hand-written custom attribute types

### SDK (`internal/sdk/`)

Generated Go HTTP client. Entry point: `graviteeapim.go`. API groups: `apis.go`, `applications.go`, `dictionaries.go`, `groups.go`, `sharedpolicygroups.go`, `subscriptions.go`, `portals.go`, `portallistings.go`, `apidocumentations.go`, `portaldocumentations.go`. Models in `models/operations/` and `models/shared/`.

### Tests (`tests/`)

All hand-written — nothing under `tests/` is generated.

- `tests/acceptance/` — resource lifecycle tests (create, read, update, delete, import) with `testdata/**/*.tf`
- `tests/examples/` — runs Terraform configs from `examples/use-cases/`
- `tests/utils/` — helpers (e.g. APIM version gating)
- Acceptance and example tests require a running APIM instance

### Examples (`examples/`)

- `examples/resources/` — minimal registry examples (hand-curated, `.genignore`)
- `examples/use-cases/` — end-to-end tutorial scenarios referenced by guides
- `examples/tutorials/` — longer walkthroughs (export, cert rotation, shared resources)

### Authentication

Provider supports three auth methods:

1. Service account token (`APIM_SA_TOKEN` / `bearer_auth`)
2. Gravitee Cloud token (`APIM_CLOUD_TOKEN` / `cloud_auth`) — resolved by `gravitee_cloud.go`
3. Basic auth (`APIM_USERNAME` / `APIM_PASSWORD`)

## Changing Provider Schema Behavior

To change schema behavior (plan modifiers, computed fields, validators, defaults, suppress diffs, etc.), update `.speakeasy/overlays/` and regenerate with `make speakeasy`. Never edit generated files directly.

Key Speakeasy overlay annotations:

- `x-speakeasy-param-computed: true` — mark a field as computed
- `x-speakeasy-param-suppress-computed-diff: true` — add `SuppressDiff` plan modifier (only works for Unknown plan values)
- `x-speakeasy-plan-modifiers: MyModifier` — reference a custom plan modifier from `internal/planmodifiers/<type>planmodifier/`

Wire custom types from overlays (see `application.yaml` for examples):

```yaml
schemaType: customtypes.TrimmedStringType{}
valueType: customtypes.TrimmedString
```

## Changing Guides and Tutorial Examples

1. Edit Terraform in `examples/use-cases/` or `examples/tutorials/`
2. Register chunks in `.docgen/config/default.yaml` if adding a new example
3. Edit prose/structure in `.docgen/config/tmpl/*.md.tmpl`
4. Run `make doc-gen` to regenerate `templates/guides/docgen_*.md`
5. Run `make speakeasy` (or `go generate ./...`) to refresh `docs/guides/` via tfplugindocs

Do not hand-edit `templates/guides/docgen_*.md` or `docs/` — they are generated outputs.

## Key Conventions

- Generated code is the majority of the codebase — extend via overlays, hand-maintained files, or marked regions
- Import IDs are JSON-encoded composite keys (see acceptance test files for format)
- APIM compatibility: 4.9+
- CI runs acceptance tests across a matrix of Terraform versions (1.9.x, latest) × APIM versions (4.9.x, 4.10.x, 4.11.x, master-latest/4.12.x)
- Issues tracked at github.com/gravitee-io/issues with tag `project: GKO`
- `make lint` verifies the `// BEGIN GRAVITEE CLOUD INIT` marker is present in `provider.go`
